## 🔑 MikyHost Module Licensing Overview

All commercial MikyHost WHMCS modules are protected by the **MikyHost License Verification System**:
1. Every module requires an active **Module License Key** (e.g., `MIKY-XXXXXXX`) issued from your [MikyHost Client Area](https://mikyhost.com).
2. When you first open or activate a MikyHost module in WHMCS, the configuration screen will prompt for your **Module License Key**.
3. Once validated against `https://mikyhost.com/check_license.php`, a signed 15-day local cache key (`localkey`) is stored automatically and all module configuration settings are unlocked immediately.
